2. Description of Application & Functional Scope

Anchor Launcher is a minimal, fast, and feature-rich Android home screen desktop replacement designed to enhance productivity, aesthetics, and digital wellbeing. Core functionality built into the App includes:

  • Home Screen Desktop & App Drawer: Custom layout management, app folder creation, application drawer organization, private space app support, and launching installed applications.
  • Clock & Quick System Shortcuts: Interactive homescreen clock bar with customizable system toggles and live status indicators (Flashlight, Wi-Fi, Bluetooth, Hotspot, Mobile Data, Sound modes, Airplane Mode, and Alarms).
  • Digital Wellbeing & Screen Time Limits: Local tracking of daily screen time, app launch counters, and reminder popups when user-configured usage thresholds are reached.
  • Smart Search, Quick Dial & Voice Search: Unified search overlay supporting local app queries, web search shortcuts, contact search with quick dialing, and hands-free voice input via speech-to-text.
  • App Lock & Biometric Security: On-device security protection for locked apps, hidden apps, and master settings utilizing Android native biometric authentication (fingerprint / face unlock) and hashed PIN credentials.
  • Weather & Native System Widgets: Real-time local weather forecasts powered ephemerally by Open-Meteo API and hosting of native Android system widgets on the home screen.
  • Built-In Local To-Do & Task Manager: Personal productivity task management and to-do lists stored locally on your device via an encrypted SQLite database.
  • Wallpapers & Personalization: Custom wallpaper selection, dynamic Material You color palette generation, curated 4K online wallpapers via Fibrly API, icon pack support, and custom haptic feedback settings.
